# Body Reset Coach

A lightweight static MVP prototype for a 21-day habit coaching product. The app focuses on daily consistency instead of exhaustive calorie counting.

## Product Focus

Body Reset Coach helps users prepare for a near-term event by tracking the few habits that create visible progress:

- Protein target: at least 100g per day
- Daily steps target
- Workout or mobility completion
- Water intake
- No sugary drinks
- Sleep consistency

## Run Locally

Because this is a static prototype, no package installation is required.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Files

- `index.html` - page structure and product sections
- `styles.css` - responsive visual design
- `app.js` - interactive habit, XP, score, and protein tracker behavior
